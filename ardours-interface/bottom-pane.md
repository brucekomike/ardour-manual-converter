# Bottom pane
The bottom pane is available on the Editor and Cue windows and can be
toggled from the application bar on the right. The functionality it
provides depends on which window you are on.

## Bottom pane in the Editor window
{#editor-window}

The bottom pane of the Editor window can display one of the two things:

-   Pianoroll editor for a selected MIDI region
-   Generic plugin UI for all plugins in the selected track

![The bottom pane in the Editor
window](https://raw.githubusercontent.com/Ardour/manual/refs/heads/master/source/images/bottom-pane-editor.png){style="width:75%"}

For documentation on using the bottom MIDI region editor, please refer
to the [Pianoroll Window](@@pianoroll-window) chapter that covers the
user interface and functionality.

For documentation on using the bottom pane plugin views, please refer to
the [Working with Ardour-built Plugin
Editors](@@working-with-ardour-built-plugin-editors) chapter.

## Bottom pane in the Cue window
{#cue-window}

The bottom pane in the Cue window always displays clip properties and
the editor for the selected audio or MIDI clip:

![The bottom pane in the Cue
window](https://raw.githubusercontent.com/Ardour/manual/refs/heads/master/source/images/bottom-pane-cue.png){style="width:75%"}

For details on setting clip properties, launch styles, etc., please read
[the relevant documentation section](@@cue-window-elements).

For details on editing clip contents, please read [Editing
Cues](@@cue-editing).
