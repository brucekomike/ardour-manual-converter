# Editor and Cue Lists
The Editor and the Cue windows have an optional area called [Editor
list]{.dfn}. It contains multiple lists: tracks and busses, sources,
regions, reusable clips, various markers etc.

<figure class="right">
<img src="https://raw.githubusercontent.com/Ardour/manual/refs/heads/master/source/images/editor-list.png" width="300" alt="Editor list" />
<figcaption aria-hidden="true">Editor list</figcaption>
</figure>

The Editor list is not shown by default when you run Ardour for the
first time. It can be hidden or shown using [View \> Show Editor
List]{.kbd .menu} menu command.

This area appears on the right side of the window. The left-hand border
of the list can be dragged to show more columns where appropriate
(alternatively, you can scroll the bottom scrollbar to see more).

The Cue window displays only a part of all possible lists --- ones that
make sense for this non-linear sequencer: Clips, Tracks, Sources, and
Regions.

It\'s possible to quickly switch between two diferent lists. To select a
list and switch to it, click on the part of the button that contains a
triangle icon pointing downwards. To switch to an already selected list,
click the main part of the button.
